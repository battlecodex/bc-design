# Sekolah Cakrawala landing page

Static BC Design demo. Open `index.html` directly, or serve the repository root:

```powershell
python -m http.server 8766 --directory .
```

Then visit `http://127.0.0.1:8766/examples/school-cakrawala/`.

The page includes light/dark mode, a mobile navigation menu, anchor navigation, and an inline visit-request status. Newsreader and Inter load from Google Fonts with Georgia/system fallbacks. The form is intentionally local-only and does not send data.
